# Personal Portfolio Website

This repository contains the source code for my personal portfolio website, designed to showcase my skills, projects, and professional experience in the fields of IT and data analytics. The site is built with modern web technologies and focuses on a clean, responsive design, fast performance, and a clear, impact-driven narrative.

**Live Portfolio:** **[https://patelmeet1011.github.io/personalporfoliotest/](https://patelmeet1011.github.io/personalporfoliotest/)**

---

## About This Project

This portfolio was built from the ground up to serve as a central hub for my professional identity. It is more than just a resume; it's an interactive demonstration of my capabilities in front-end development, UX/UI principles, and, most importantly, my ability to communicate complex technical work in a clear and compelling manner.

The development process followed the principles of world-class portfolio design, including:
* **Targeted Content Strategy:** All content is tailored to a primary audience of recruiters and hiring managers, focusing on quantifiable results and the STAR (Situation, Task, Action, Result) method for project descriptions.
* **Responsive & Accessible Design:** The site is fully responsive and adheres to WCAG accessibility standards, ensuring a seamless experience on all devices for all users.
* **Performance Optimization:** Assets are optimized, and scripts are loaded efficiently to ensure fast page load times.

## Key Features

* **Light/Dark Mode Theme:** A user-toggleable theme switcher for personalized viewing comfort.
* **Dynamic Project Filtering:** An interactive filter on the homepage to easily sort projects by technology or skill area.
* **Interactive Animations:** Subtle on-scroll animations (AOS) and an animated background (Vanta.js) to create an engaging user experience.
* **Detailed Project & Academic Pages:** Individual pages for deep dives into specific projects, coursework, and certifications.
* **SEO & Social Sharing:** Custom meta tags for each page ensure professional, rich previews when shared on platforms like LinkedIn and Twitter.

## Technologies Used

* **Front-End:** HTML5, CSS3, JavaScript (ES6+)
* **Frameworks/Libraries:**
    * [Bootstrap 5.3](https://getbootstrap.com/) for the responsive grid system and core components.
    * [Animate on Scroll (AOS)](https://michalsnik.github.io/aos/) for scroll animations.
    * [Vanta.js](https://www.vantajs.com/) for the animated hero background.
* **Tooling:** Git & GitHub for version control and hosting via GitHub Pages.
